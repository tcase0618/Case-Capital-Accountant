# ROIC: Return on Invested Capital

**Version:** 1.0  
**Date:** 2026-08-12  
**Purpose:** Detailed reference for ROIC calculation methodology in THE ACCOUNTANT.

---

## Executive Summary

**ROIC** measures the efficiency of capital deployment — how much profit is generated per dollar of capital invested in the business.

**Formula:**
```
ROIC = NOPAT / Average Invested Capital × 100%
```

**Components:**
1. **NOPAT:** Net Operating Profit After Tax
2. **Invested Capital:** Capital deployed for operations

---

## 1. NOPAT (Net Operating Profit After Tax)

### Definition

NOPAT is the profit generated by core operations, adjusted for a normalized tax rate, excluding financing effects.

### Formula

```
NOPAT = Operating Income × (1 - Tax Rate)
```

### Components

**Operating Income** (from income statement)
- Revenue
- Less: Cost of Revenue
- Less: Operating Expenses (R&D, SG&A)
- Equals: Operating Income (EBIT)

**Tax Rate** (multiple sources):
1. **Explicit Override:** User-provided rate
2. **Reported Effective Tax Rate:** From income statement
   - Formula: Income Tax / Pretax Income
   - Validation: Only use if in range [0%, 50%]
3. **Statutory Fallback:** 21% (US federal corporate rate)

### Calculation Steps

```python
# Step 1: Get operating income
operating_income = income_stmt.lines["CC_OPERATING_INCOME"].value_numeric

# Step 2: Determine tax rate
if tax_rate_override:
    tax_rate = tax_rate_override
else:
    tax_rate = _infer_tax_rate(income_stmt)

# Step 3: Calculate NOPAT
nopat = operating_income * (1 - tax_rate)

# Step 4: Capture metadata
result.metadata["tax_rate_used"] = tax_rate
result.metadata["tax_rate_source"] = "override" | "reported" | "fallback"
```

### Tax Rate Inference Logic

```python
def _infer_tax_rate(income_stmt, override=None):
    """Infer tax rate using hierarchy."""
    
    # 1. Explicit override (highest priority)
    if override is not None:
        if 0 <= override <= 0.5:
            return override
        else:
            warn("Tax rate override out of range [0, 0.5]")
    
    # 2. Reported effective tax rate
    pretax = income_stmt.lines.get("CC_PRETAX_INCOME")
    tax = income_stmt.lines.get("CC_INCOME_TAX")
    
    if pretax and tax and pretax.value_numeric and tax.value_numeric:
        if abs(pretax.value_numeric) > ZERO_THRESHOLD:
            etr = tax.value_numeric / pretax.value_numeric
            if 0 <= etr <= 0.5:
                return etr
            else:
                warn("Reported ETR out of range; using fallback")
    
    # 3. Statutory fallback
    warn("No valid tax rate found; using 21% statutory rate")
    return 0.21
```

### Example

**AAPL FY2024 (example data):**
- Operating Income: $150B
- Pretax Income: $155B
- Income Tax: $31B
- Effective Tax Rate: 31B / 155B = 20%
- NOPAT: $150B × (1 - 0.20) = $120B

### Status Codes

- **VALID:** Normal calculation with clear inputs
- **INSUFFICIENT_DATA:** Missing operating income or tax data
- Warnings:
  - Tax rate out of range → fallback to 21%
  - Operating income missing → INSUFFICIENT_DATA
  - Negative operating income → VALID (but note in warnings)

## 2. Invested Capital (IC)

### Definition

Invested Capital is the total capital deployed to generate operating income. It represents the cumulative investment in the business from all sources (debt, equity, and retained earnings).

### Two Methods

THE ACCOUNTANT implements both methods for cross-validation:

#### Method 1: Operating Method

**Formula:**
```
IC = Operating Assets - Operating Liabilities
```

**Components:**

**Operating Assets:**
- Total Assets
- Less: Cash & Short-Term Investments (non-operating)

**Operating Liabilities:**
- Accounts Payable (interest-free)

**Calculation:**
```python
total_assets = bs.lines["CC_TOTAL_ASSETS"].value_numeric
cash = bs.lines["CC_CASH"].value_numeric or 0
short_term_inv = bs.lines["CC_SHORT_TERM_INVESTMENTS"].value_numeric or 0
operating_assets = total_assets - cash - short_term_inv

accounts_payable = bs.lines["CC_ACCOUNTS_PAYABLE"].value_numeric or 0

ic = operating_assets - accounts_payable
```

**Interpretation:**
- IC represents capital tied up in operations
- Excludes cash (available for distribution)
- Excludes financial liabilities (accounted for in WACC)

#### Method 2: Financing Method (Deferred to Prompt 8)

**Formula:**
```
IC = Debt + Equity - Excess Cash
```

This method will verify that both approaches yield the same IC value.

### Average Invested Capital

For ROIC, we use **average IC** over the period:

```
Average IC = (Beginning IC + Ending IC) / 2
```

This smooths single-period variations in working capital and capital structure.

### Calculation with Multi-Year Comparison

```python
def calculate_invested_capital(bs_current, bs_prior=None):
    """Calculate IC with average support."""
    
    # Current period IC
    ic_ending = calculate_operating_method(bs_current)
    
    # Prior period IC (for averaging)
    ic_beginning = None
    if bs_prior:
        ic_beginning = calculate_operating_method(bs_prior)
    
    # Average for ROIC denominator
    if ic_beginning:
        ic_average = (ic_beginning + ic_ending) / 2
    else:
        ic_average = ic_ending
        warn("Prior-year balance sheet unavailable; using period-end IC")
    
    # Store all three for audit trail
    result.metadata["beginning_ic"] = ic_beginning
    result.metadata["ending_ic"] = ic_ending
    result.metadata["average_ic"] = ic_average
    
    return result
```

### Example

**AAPL FY2024:**

**Balance Sheet (FY2023):**
- Total Assets: $350B
- Cash: $30B
- ST Investments: $25B
- Accounts Payable: $50B
- Operating Assets: 350 - 30 - 25 = $295B
- IC (2023): 295 - 50 = $245B

**Balance Sheet (FY2024):**
- Total Assets: $380B
- Cash: $35B
- ST Investments: $30B
- Accounts Payable: $55B
- Operating Assets: 380 - 35 - 30 = $315B
- IC (2024): 315 - 55 = $260B

**Average IC:** (245 + 260) / 2 = $252.5B

## 3. ROIC Calculation

### Formula

```
ROIC = NOPAT / Average IC × 100%
```

### Calculation Steps

```python
def calculate_roic(income_stmt, bs_current, bs_prior, context, tax_rate_override=None):
    """Calculate ROIC with full audit trail."""
    
    # Step 1: Calculate NOPAT
    nopat_result = NOPATCalculator.calculate_nopat(
        income_stmt, context, tax_rate_override
    )
    if nopat_result.calculation_status != "VALID":
        return CalculationResult(
            calculation_id="ROIC",
            value=None,
            calculation_status="INSUFFICIENT_DATA",
            warnings=[f"NOPAT calculation failed: {nopat_result.warnings}"]
        )
    
    nopat = nopat_result.value
    
    # Step 2: Calculate Invested Capital
    ic_result = InvestedCapitalCalculator.calculate_operating_method(
        bs_current, bs_prior, context
    )
    if ic_result.calculation_status != "VALID":
        return CalculationResult(
            calculation_id="ROIC",
            value=None,
            calculation_status="INSUFFICIENT_DATA",
            warnings=[f"IC calculation failed: {ic_result.warnings}"]
        )
    
    ic_average = ic_result.metadata["average_ic"]
    
    # Step 3: Calculate ROIC
    if ic_average < ZERO_THRESHOLD:
        return CalculationResult(
            calculation_id="ROIC",
            value=None,
            calculation_status="INSUFFICIENT_DATA",
            warnings=["Invested capital near zero; ROIC undefined"]
        )
    
    roic = (nopat / ic_average) * 100
    
    # Step 4: Build result with full audit trail
    result = CalculationResult(
        calculation_id="ROIC",
        formula_version=ROIC_V1,
        company_id=context.company_id,
        fiscal_year=context.fiscal_year,
        fiscal_quarter=context.fiscal_quarter,
        value=roic,
        unit="%",
        formula="NOPAT / Average IC × 100",
        inputs={
            "nopat": nopat,
            "ic_average": ic_average,
            "ic_beginning": ic_result.metadata.get("beginning_ic"),
            "ic_ending": ic_result.metadata.get("ending_ic"),
            "tax_rate": nopat_result.metadata.get("tax_rate_used"),
        },
        metadata={
            "nopat": nopat,
            "beginning_ic": ic_result.metadata.get("beginning_ic"),
            "ending_ic": ic_result.metadata.get("ending_ic"),
            "average_ic": ic_average,
            "tax_rate_source": nopat_result.metadata.get("tax_rate_source"),
        },
        calculation_status="VALID",
        warnings=nopat_result.warnings + ic_result.warnings,
    )
    
    return result
```

### Example

**AAPL FY2024:**
- NOPAT: $120B
- Average IC: $252.5B
- ROIC: (120 / 252.5) × 100 = 47.5%

### Interpretation

| ROIC | Interpretation |
|------|---|
| < 5% | Poor capital efficiency |
| 5-10% | Below cost of capital (typically) |
| 10-15% | Adequate but not exceptional |
| 15-25% | Strong capital discipline |
| > 25% | Exceptional returns; potential moat |

## 4. Quality Considerations

### Sources of Error

1. **Tax Rate Estimation:** Using statutory rate instead of actual can skew ROIC ±2-5%
2. **Operating/Non-Operating Segregation:** Misclassifying assets can shift IC ±5-10%
3. **Prior-Year Data:** Falling back to period-end IC instead of average smoothing ~2-3%
4. **Lease Capitalization:** Operating leases treated as debt vs. expensed ~1-3%

### Warnings That Trigger

- Tax rate out of range → falls back to 21% statutory
- Missing prior-year balance sheet → uses period-end IC
- Negative operating income → ROIC negative (but valid)
- IC near zero → INSUFFICIENT_DATA status
- Very high ROIC (>100%) → investigate data quality

### Best Practices

1. **Review input statements first:** Balance sheet and income statement quality matters
2. **Compare both methods:** Operating and financing methods should be close
3. **Multi-year trends:** Look at ROIC over time, not single period
4. **Sector context:** Compare ROIC to peers and WACC

## 6. Database Persistence

ROIC calculations are persisted to `calculation_results` table:

```sql
SELECT
    calculation_id,
    fiscal_year,
    fiscal_quarter,
    value,
    calculation_status,
    metadata,
    calculated_at
FROM calculation_results
WHERE company_id = :company_id
  AND calculation_id = 'ROIC'
ORDER BY fiscal_year DESC;
```

This enables:
- Historical ROIC tracking
- Multi-year trend analysis
- Audit trails for regulatory review
- Reproducibility (same calculation re-executed produces same result)
